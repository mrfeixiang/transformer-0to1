왜 Transformer인가?

생물정보학에서 Transformer가 혁명을 일으킨 이유

🧬

서열은 언어다

DNA, RNA, 단백질 서열은 문자열(sequence)이다. 자연어처리(NLP) 기술이 곧바로 적용 가능하다.

⚡

장거리 의존성

단백질의 접촉 잔기(contact residue)는 서열상 멀리 떨어져 있지만, 3D 공간에서는 인접하다. Transformer는 이를 포착한다.

🚀

병렬 처리

RNN과 달리 모든 위치를 동시에 처리할 수 있어, 대규모 유전체·단백질 데이터에 적합하다.

토큰화와 임베딩

서열 → 숫자 벡터: Transformer의 첫 번째 단계

🧬 생물학적 서열의 토큰화

DNA: 각 뉴클레오타이드 (A, T, G, C) 또는 k-mer 단위
단백질: 각 아미노산 (20종 + 특수 토큰)
RNA: 각 뉴클레오타이드 (A, U, G, C)

DNA 서열 예시 (k-mer = 3):

ATG TGC GCA CAT ATG

단백질 서열 예시:

M A L W K R L L

📐 임베딩 (Embedding)

각 토큰을 고차원 벡터(예: 768차원)로 변환한다.
학습을 통해 의미적으로 유사한 토큰이 가까운 벡터를 갖게 된다.

# 단백질 임베딩 예시 (PyTorch) import torch.nn as nn vocab_size = 25 # 20 AA + 특수토큰 d_model = 768 embedding = nn.Embedding(vocab_size, d_model) # "MALWKRLL" → [12,0,11,22,10,17,11,11] seq = torch.tensor([12,0,11,22,10,17,11,11]) emb = embedding(seq) # (8, 768)

위치 인코딩 (Positional Encoding)

순서 정보가 없는 Transformer에 위치 감각을 부여하는 방법

왜 필요한가?

  • RNN은 순차 처리 → 위치 정보가 내재
  • Transformer는 모든 토큰을 동시에 봄 → 위치 정보가 없다!
  • 서열에서 위치는 중요: 같은 아미노산이라도 위치에 따라 기능이 다르다

수학적 정의

PE(pos, 2i) = sin(pos / 10000^(2i/d)) PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

pos = 서열에서의 위치, i = 차원 인덱스, d = 임베딩 차원

🧬 생물정보학에서의 변형

학습 가능한 위치 인코딩

ESM, ProtTrans 등은 sin/cos 대신 학습 가능한 파라미터를 사용하여 단백질 서열의 특성에 맞게 최적화

상대적 위치 인코딩 (RPE)

AlphaFold에서 사용. 절대 위치가 아닌 잔기 간 상대적 거리를 인코딩 → 서열 길이에 더 잘 일반화

Rotary Position Embedding (RoPE)

최신 모델(ESM3 등)에서 채택. 회전 변환으로 상대 위치를 내적(dot product)에 자연스럽게 반영

Self-Attention이란?

"이 서열에서 어떤 위치가 어떤 위치에 중요한가?"를 계산하는 메커니즘

핵심 아이디어

  • 각 토큰이 다른 모든 토큰과의 관련성(attention score)을 계산
  • 관련성이 높은 토큰의 정보를 더 많이 반영
  • 서열의 길이와 무관하게 모든 쌍을 한 번에 비교
생물학적 의미: 단백질 서열에서 Self-Attention은 3D 공간에서 가까운 잔기 쌍(contact map)을 자동으로 학습한다. Attention weight ≈ 잔기 간 거리의 역수!

직관적 비유

🔍

Query-Key-Value 비유

도서관에서 책을 찾을 때:

  • Query (Q) — "이 잔기는 누구와 상호작용하고 싶나?" (검색어)
  • Key (K) — "나는 이런 특성을 가진 잔기야" (책 제목)
  • Value (V) — "나의 실제 정보는 이거야" (책 내용)

Q와 K의 유사도가 높을수록, 해당 V의 비중이 커진다.

Scaled Dot-Product Attention

Attention(Q, K, V) = softmax(QKT / √dk) V

QKT

Query와 Key의 내적 → 유사도 행렬 (n×n)
각 토큰 쌍의 관련성 점수

√dk 로 나누기

차원이 커지면 내적 값도 커짐 → softmax가 극단적 분포가 됨. 스케일링으로 안정화

Softmax

점수를 확률 분포로 변환. 합이 1이 되어 가중 평균으로 사용 가능

× V

확률 분포로 Value를 가중 합산. 관련성 높은 위치의 정보를 더 많이 취합

단계별 계산 예시

# 서열 길이 4, d_k = 3 Q = [[1,0,1], [0,1,1], [1,1,0], [0,0,1]] K = [[1,1,0], [0,1,1], [1,0,1], [1,1,1]] # Step 1: QK^T (4×4 유사도 행렬) scores = Q @ K.T # [[1,1,2,2], [1,2,1,2], [2,1,1,2], [0,1,1,1]] # Step 2: Scale by √d_k = √3 ≈ 1.73 scores = scores / 1.73 # Step 3: Softmax (각 행의 합 = 1) weights = softmax(scores, dim=-1) # Step 4: Weighted sum of V output = weights @ V # (4, 3)

* 행렬 곱셈이므로 GPU에서 대규모 병렬 연산 가능

Multi-Head Attention

여러 관점에서 동시에 attention을 수행하는 메커니즘

왜 여러 개의 Head가 필요한가?

  • 하나의 attention head는 하나의 관계 유형만 포착
  • 단백질에는 여러 유형의 상호작용이 공존:
    • 수소 결합 패턴
    • 소수성(hydrophobic) 상호작용
    • 정전기적 상호작용
    • 이황화 결합(S-S bond)
  • 각 head가 서로 다른 상호작용을 학습!
MultiHead(Q,K,V) = Concat(head₁, ..., headₕ) Wᴼ headᵢ = Attention(QWᵢᵠ, KWᵢᴷ, VWᵢⱽ)

8개 Head가 각각 다른 패턴을 학습하는 모습

각 Head를 클릭하면 해당 attention 패턴을 확인할 수 있습니다

ESM-1b의 발견: 특정 attention head가 단백질의 접촉 맵(contact map)과 높은 상관관계를 보인다는 것이 밝혀짐. 즉, Transformer가 3D 구조를 서열만으로 암묵적으로 학습한다!

FFN, 잔차 연결, LayerNorm

Transformer 블록의 나머지 핵심 구성 요소

🔄

Feed-Forward Network (FFN)

각 위치에 독립적으로 적용되는 2층 MLP.

FFN(x) = max(0, xW₁ + b₁)W₂ + b₂ # 보통 d_ff = 4 × d_model # 768 → 3072 → 768

Attention이 "어디를 볼지" 결정하면, FFN이 "무엇을 추출할지" 결정한다.

➕

잔차 연결 (Residual)

입력을 출력에 더해준다:

output = x + SubLayer(x)

왜? 깊은 네트워크에서 기울기 소실 방지. 정보의 "고속도로" 역할.

📏

Layer Normalization

각 샘플 내에서 평균 0, 분산 1로 정규화:

LN(x) = γ · (x - μ) / σ + β

학습을 안정화하고 수렴 속도를 높인다. Pre-LN vs Post-LN 변형이 있다.

Self-Attention PyTorch 구현

핵심 코드를 직접 작성해보기

import torch import torch.nn as nn import torch.nn.functional as F class SelfAttention(nn.Module): def __init__(self, d_model, n_heads): super().__init__() self.d_k = d_model // n_heads self.n_heads = n_heads # Q, K, V 투영 행렬 self.W_q = nn.Linear(d_model, d_model) self.W_k = nn.Linear(d_model, d_model) self.W_v = nn.Linear(d_model, d_model) self.W_o = nn.Linear(d_model, d_model) def forward(self, x): B, L, D = x.shape # Multi-head 분리 Q = self.W_q(x).view(B,L,self.n_heads,self.d_k) K = self.W_k(x).view(B,L,self.n_heads,self.d_k) V = self.W_v(x).view(B,L,self.n_heads,self.d_k) Q, K, V = [t.transpose(1,2) for t in (Q,K,V)] # Scaled dot-product attention scores = Q @ K.transpose(-2,-1) / self.d_k**0.5 attn = F.softmax(scores, dim=-1) out = attn @ V # Head 합치기 out = out.transpose(1,2).reshape(B,L,D) return self.W_o(out)

코드 해설

1. 투영 (Projection)

입력 x를 W_q, W_k, W_v로 변환하여 Q, K, V 생성. 각 행렬은 d_model × d_model 크기.

2. Multi-Head 분리

d_model을 n_heads 개로 분할. 예: 768 = 12 heads × 64 dim. 각 head가 독립적으로 attention 수행.

3. Attention 계산

QK^T / √d_k → softmax → × V. 행렬 연산으로 효율적 병렬 처리.

4. 출력 투영

모든 head의 결과를 concat 후 W_o로 투영하여 최종 출력 생성.

효율적 Attention

Flash Attention, Linear Attention — O(n²) 메모리 문제를 해결하여 전체 유전체 수준의 입력 처리 가능

Hyena, Mamba — Attention 없이 긴 서열 처리가 가능한 SSM(State Space Model) 기반 아키텍처
🎨

생성형 생물 AI

서열을 이해하는 것을 넘어 새로운 단백질/DNA를 설계. 신약 개발, 효소 공학에 혁명적 변화.

RFdiffusion ProtGPT2 ESM3
🌐

멀티모달 모델

서열 + 구조 + 기능 + 텍스트를 하나의 모델에서 통합 학습. AlphaFold 3은 단백질뿐 아니라 DNA, RNA, 리간드까지 복합체 구조 예측.

🧫

단일 세포 Transformer

scGPT, Geneformer — 단일 세포 RNA-seq 데이터를 Transformer로 분석. 세포 유형 분류, 유전자 네트워크 추론에 활용.

핵심 요약

오늘 배운 내용을 정리합니다

1. Transformer 아키텍처

  • Self-Attention: 모든 위치 쌍의 관련성을 계산
  • Multi-Head: 다양한 관계 유형을 동시에 포착
  • 위치 인코딩: 순서 정보를 벡터에 주입
  • FFN + 잔차 연결: 특징 추출과 학습 안정화

2. 생물정보학 응용

  • 단백질 언어 모델: ESM, ProtTrans (MLM 학습)
  • 구조 예측: AlphaFold (Evoformer)
  • 유전체: DNABERT, Enformer, Evo
  • 단일 세포: scGPT, Geneformer

Take-Home Message

Transformer는 서열을 이해하는 범용 엔진이다.
자연어든, DNA든, 단백질이든 — "Attention Is All You Need."
생물정보학자가 Transformer를 이해하는 것은 선택이 아닌 필수다.
